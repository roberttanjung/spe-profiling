## Atomic Design

Ikut berkontribusi pada pengerjaan Atomic Design untuk membuat component reusebale. Adapun component yang telah dikerjakan adalah sebagai berikut:

- `Tooltip`: Sebuah wadah yang melayang pada sebuah konten guna memberikan pendetailan terhadap konten tersebut.
- `Rating`: Component yang dapat menampilkan Rating dalam bentuk bintang guna memperlihatkan kepuasaan user.
- `Document File`: Sebuah input yang dapat menyimpan data file secara komprehensif (asynchrounous, delete, edit and disabled).
- `thousand`: Sebuah fungsi yang mampu merubah format angka menjadi ribuan dengan separasi yang dapat dikustomisasi. Juga, mampu menangani masalah yang sempat ramai dibicarakan yaitu redenominasi.
